# About

## Cite

If you use MembraneForger, cite this repository with
[CITATION.cff](https://github.com/rolanddelmundo/MembraneForger/blob/main/CITATION.cff), together with the tools it
builds on: Martini 3, mstool, CHARMM36, CHARMM-GUI, CGenFF, GROMACS, and PPM 3.0 or OPM when you use them for
orientation.

## Built on

| Tool | Used for |
|---|---|
| [Martini 3](https://cgmartini.nl/) | the coarse-grained plasma membranes |
| [mstool](https://github.com/ksy141/mstool) | backmapping the membrane to all atoms |
| [CHARMM36 and CHARMM-GUI](https://www.charmm-gui.org/) | the force field and the equilibration schedule |
| [CGenFF](https://cgenff.com/) | ligand parameters |
| [GROMACS](https://www.gromacs.org/) | topology checks, solvation and minimization |
| [OPM and PPM 3.0](https://opm.phar.umich.edu/) | membrane orientation |
